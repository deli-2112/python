## Tentang Proyek

Repositori ini adalah dokumentasi belajar Python dari dasar untuk tugas mata pelajaran di SMKN 2 Sibolga. Materi mengikuti kursus Python untuk pemula dari Santrikoding, mulai dari instalasi Python sampai pembuatan class dan object.

Setiap bab dikerjakan dan di-commit terpisah, sehingga perkembangan belajar bisa dilihat dari riwayat commit. Tiap commit berisi kode latihan sesuai sub-materi, dan hasil eksekusinya didokumentasikan dengan screenshot di folder `screenshots/`.

### Materi yang Dipelajari
- Pengenalan dan instalasi Python
- Variabel dan tipe data
- Operator
- Kondisi if-else
- Perulangan
- List dan dictionary
- Function
- Class dan object
- PIP dan virtual environment
- Konfigurasi environment/IDE
- Dokumentasi proyek (README.md dan requirements.txt)

### Tujuan
- Memahami dasar pemrograman Python
- Terbiasa memakai Git dan GitHub untuk mencatat progres
- Menyusun repositori yang rapi dan lengkap (README, requirements, .gitignore)
